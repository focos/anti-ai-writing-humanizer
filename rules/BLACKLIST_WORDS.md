# 表达审查词表

以下表达是上下文检查线索，不是检测器黑名单。引文、术语及合理逻辑说明不自动改动。

| 表达 | 检查问题 | 可行处理 |
|---|---|---|
| 赋能、抓手、多维度、全方位 | 是否交代谁做了什么？ | 用原稿已有的动作说明；缺少事实则收敛表述 |
| 具有重要意义、深远影响 | 影响谁、体现在哪？ | 写已有证据支持的范围，删去无支撑评价 |
| 值得注意、显而易见 | 是否只是重复提醒？ | 删除无作用的引导，保留有实际强调作用的表达 |
| 首先、其次、最后 | 是否确有顺序？ | 有步骤就保留，无顺序则按论证关系组织 |
| 不仅而且、一方面另一方面 | 是否有真实并列关系？ | 保留准确关系，减少连续复制同一结构 |
| 未来可期、行稳致远 | 结尾是否提出有用结论？ | 改为正文支持的判断，不强制改成场景 |
| 在某种程度上、可能、部分 | 是否限定了结论？ | 通常保留，不能作为空话批量删除 |
| 闭环、阈值、显著 | 是否是专业或统计术语？ | 保留含义和定义，不换成随意口语 |

冒号、引号、破折号、括号、分号没有通用禁令。不得用同义词替换掩盖缺少论据。
